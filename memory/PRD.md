# PRD — Ирис Design Landing Page

## Problem Statement
Создание лендинга для студии дизайна интерьеров «Ирис Design» с анимациями, параллаксом, интерактивным FAQ и адаптивной вёрсткой.

## User Personas
- Потенциальные клиенты (домовладельцы, покупатели квартир)
- Партнёры (застройщики, архитекторы, поставщики)
- Соискатели (дизайнеры, ищущие работу)

## Core Requirements
- Цветовая палитра: #be1f33, #ffffff, #9ed5dc, #2f8791, #3d6f56
- Шрифты: Outfit, Manrope, Caveat
- Русский язык

## What's Been Implemented (30.03.2026)
- Hero: слайд-шоу из 4 фото, логотип «Ирис Design», маркиз, стикер акции, CTA
- About: тёплый фон, полароид, декоративные квадраты, текст с выделением
- Services: 3 карточки (Дизайн-проект, Реализация, Авторский надзор), анимация при скролле
- Philosophy: тёмно-зелёный фон, 6 преимуществ, штамп «Сервис 360°»
- Portfolio: 3 проекта с параллакс-эффектом, рукописные подписи, CTA
- Team: фото команды, рваная бумага, кнопка «Присоединиться», список преимуществ
- Partnership: фото проектов, стикеры, CTA «Стать партнёром»
- FAQ: аккордеон с анимацией +/x, красные линии
- Footer: контакты, навигация, лого партнёров
- Header: фиксированный с маркиз и гамбургер-меню
- Анимации: framer-motion scroll reveals, параллакс, wobble стикер

## Testing: 100% passed (frontend)
